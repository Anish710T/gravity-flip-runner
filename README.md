# Gravity Flip Runner

An endless runner you play in the browser. Flip gravity to run on the floor or the ceiling, dodge spikes and walls, and grab gold orbs for bonus points. The game speeds up the longer you survive.

## How to play

| Action | Keys |
| --- | --- |
| Flip gravity | `Space`, `↑` / `↓`, `W` / `S`, or tap the screen |
| Start / restart | `Space` or `Enter` |
| Pause | `P` or `Esc` |

- You can only flip while you're touching the floor or ceiling.
- Gold orbs are worth +25 points.
- Your best score is saved in your browser.

## Run it

It's a single HTML file with no build step. Open `index.html` in any modern browser.

To host it for free, make the repository public and turn on GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
